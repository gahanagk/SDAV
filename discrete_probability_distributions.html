Binomial Distribution

The binomial distribution describes the number of successes in a fixed number of independent trials, each with the same probability of success.

Distribution parameters

Enter a positive integer.
Enter a value from 0 to 1, inclusive.
Selected values: n = 20, p = 0.35

Statistical measures

Probability Mass Function (PMF)

P(X = k) = C(n,k) pk (1-p)n-k
P(X = k)—

This is the probability of getting exactly k successes in n trials.

Interpretation

The PMF gives the probability of each possible number of successes, from 0 through n.

Cumulative Distribution Function (CDF)

P(X ≤ k)—P(X > k)—

P(X ≤ k) means the probability of getting k or fewer successes.

Poisson Distribution

The Poisson distribution models the number of events occurring in a fixed interval of time, space or another defined unit, when events occur at a constant average rate.

Distribution parameter

λ represents the average number of events in a fixed interval. Enter a non-negative number.
Selected value: λ = 4
P(X = k) = (e−λ × λk) / k!

Statistical measures

Probability Mass Function (PMF)

P(X = k) = (e−λ × λk) / k!
P(X = k)—

Interpretation

This is the probability of observing exactly k events in the specified interval.

Cumulative Distribution Function (CDF)

P(X ≤ k)—P(X > k)—

P(X ≤ k) means the probability of observing k or fewer events in the specified interval.

Poisson PMF graph

The dashed vertical line indicates the mean λ. Hover over a bar to see its probability.

Geometric Distribution

The geometric distribution models the number of independent trials needed to obtain the first success. Here, X is the trial number on which the first success occurs: X = 1, 2, 3, ... .

Distribution parameter

p is the probability of success on each independent trial and remains constant from trial to trial. Enter a value greater than 0 and at most 1.
Selected value: p = 0.35
P(X = k) = (1-p)k−1 × p

Statistical measures

Probability Mass Function (PMF)

P(X = k) = (1-p)k−1 × p
P(X = k)—

Interpretation

This is the probability that the first success occurs exactly on trial k.

Cumulative Distribution Function (CDF)

P(X ≤ k)—P(X > k)—

P(X ≤ k) means the probability that the first success occurs on or before trial k. P(X > k) is the probability of getting no successes in the first k trials.

Geometric PMF graph

The dashed vertical line indicates the mean 1/p. Hover over a bar to see its probability.
